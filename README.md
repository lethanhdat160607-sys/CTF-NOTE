# 🚩 Danny's CTF & Security Lab
*Information Security Student | CTF Player | Low-Level Systems*

> Welcome to my training ground. Documenting CTF write-ups, exploit scripts, and security research across key domains.

## ⚡ CTF Domains & Tracked Categories

* **Pwn:** Binary exploitation, memory corruption (`Buffer Overflows`, `Heap`), and remote shellcoding using **Pwntools**.
* **Reversing:** Static/dynamic analysis of `ELF/PE` binaries, architecture profiling (`x86-64`, `ARM`), and assembly debugging via **GDB**.
* **Forensics:** Digital investigation covering memory dumps, network traffic (`PCAPs`), and file system artifacts.
* **Crypto:** Implementation, analysis, and breaking of classical/modern cryptographic schemes (`RSA`, `AES`, `ECC`) via Python.
* **Web:** Exploiting server-side/client-side vulnerabilities (`SQLi`, `XSS`, `SSRF`, `IDOR`) utilizing **Burp Suite Professional**.
* **Misc:** Miscellaneous challenges, scripting automation, steganography, and algorithmic problem-solving.
* **AI Security:** Exploring vulnerabilities, safety challenges, and algorithmic dynamics intersecting with machine learning models.
